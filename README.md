# Don't Close This Tab

A browser tab that knows you want to leave. It writes down every attempt.

**Play:** https://connabyss.github.io/dont-close-this-tab/

- Switch away and the tab title starts begging.
- There's a close button on the page. It runs.
- Find all 10 ways the tab can notice you leaving. Each one goes in the Departure Log.

It never stops you from closing it. Every line it says is something it actually measured.
One HTML file, no tracking, nothing sent anywhere. Your visits are kept only in your own browser.
